VNAU STUDENT SPACE 2.0 — VIOLET AURA
===================================

ЦЕ ОНОВЛЕННЯ ІНТЕРФЕЙСУ, НЕ ЗАМІНА ПАРСЕРА!

1. Відкрийте репозиторій https://github.com/yaroshandriy16-beep/Vnau_rozklad_par
2. Замініть у корені репозиторію три файли:
   - index.html
   - style.css
   - app.js
3. НЕ ВИДАЛЯЙТЕ папки data/, .github/, parser.py та файли розкладу.
4. Перевірте, що на GitHub є:
   data/catalog.json
   data/groups/3641.json (і файли інших груп)
5. Дочекайтеся публікації GitHub Pages, відкрийте:
   https://yaroshandriy16-beep.github.io/Vnau_rozklad_par/
6. Якщо видно старий дизайн, перезапустіть Telegram Mini App або очистьте кеш.

ЩО ПРАЦЮЄ В ЦІЙ ВЕРСІЇ:
- Violet Aura, автоматична/темна/світла тема, адаптивний дизайн.
- Головний екран: поточна/наступна пара, живий таймер, сьогоднішній розклад,
  швидкі дії, дедлайни, зміни, статистика, тижневий огляд, віджети.
- Розклад: день/тиждень/місяць, вибір факультету/курсу/групи,
  пошук, деталі заняття, експорт .ics, друк/PDF через браузер.
- Завдання і нотатки: створення, редагування, виконання, видалення.
- Улюблені групи, журнал виявлених змін, локальний кеш,
  резервне копіювання/відновлення персональних даних.
- Налаштування: тема, анімації, тактильний відгук, віджети.
- Посилання на конкретну групу ?group=3641.

ОБМЕЖЕННЯ / НАСТУПНІ ЕТАПИ:
- Сповіщення Telegram у фоновому режимі потребують окремого бота/сервера.
- Синхронізація між пристроями потребує серверного сховища.
- Карта корпусів потребує перевірених адрес.
- XP/досягнення: базові цілі є, повну систему XP ще треба додати.
- Порівняння розкладів друзів, спільні нагадування, розширений
  режим сесії та push-сповіщення — заплановані, але не реалізовані.
- Зміни визначаються лише після збереження попередньої версії розкладу
  на конкретному пристрої. Перейменування заняття може відобразитися
  як видалення старого + додавання нового запису.
- Дані занять залежать від роботи парсера та наявності майбутніх дат.

ПРИВАТНІСТЬ:
Завдання та нотатки зберігаються у localStorage цього браузера/Telegram.
При очищенні даних вони можуть зникнути: робіть резервну копію.
