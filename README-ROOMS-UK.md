# ДеПара? — вільні аудиторії

Розділ «Аудиторії» підключено до `data/campus/free-classrooms.json`. Є пошук, фільтр за місткістю, перемикач «Лише вільні», час знімка та посилання на офіційне джерело.

**Увага:** GitHub Actions у цьому репозиторії записує лише ОДНУ дату й ОДИН номер пари у JSON (за замовчуванням поточний день Києва, 2-га пара). Тому застосунок показує дату/пару фактичного знімка, але не дозволяє обирати іншу дату/пару без відповідних даних. Це не статус у реальному часі.

## Встановлення

Завантажити всі файли та папки архіву в корінь GitHub-репозиторію зі збереженням структури; існуючі файли будуть оновлені. GitHub Pages опублікує інтерфейс. За потреби у вкладці Actions запустити `Update VNAU free classrooms` вручну.

Файли основного парсера груп і workflows залишено без змін.
