# Telegram Mini App розкладу ВНАУ — стартова версія

## Файли
- `index.html` — структура екранів та елементи керування.
- `style.css` — адаптивний дизайн Dark Neon + Glassmorphism.
- `app.js` — пошук, відлік до наступної пари, теми, кеш, імпорт JSON і центр надійності.
- `schedule.json` — дані розкладу. Навмисно порожній шаблон: фактичні заняття не вигадувалися.

## Формат schedule.json
Додайте заняття до масиву `lessons` у такому форматі:

```json
{
  "meta": {
    "university": "ВНАУ",
    "faculty": "Технологічний факультет",
    "course": "3",
    "group": "ЕІ 23-1",
    "source": "http://81.30.162.30/time-table/group?type=0",
    "updatedAt": "2026-10-15"
  },
  "lessons": [
    {
      "date": "2026-10-16",
      "start": "09:00",
      "end": "10:20",
      "subject": "Назва дисципліни з офіційного розкладу",
      "room": "Номер аудиторії",
      "teacher": "ПІБ викладача",
      "type": "Лекція",
      "note": ""
    }
  ]
}
```

Це лише приклад структури, НЕ фактичне заняття. Замініть демонстраційні значення перевіреними даними. Формат дати — `YYYY-MM-DD`, час — `HH:MM` у локальному часі України.

## Важливо про оновлення
GitHub Pages не читає автоматично приватний/старий HTTP-сайт, якщо браузер блокує запит через CORS або змішаний вміст. Ця версія завантажує `schedule.json` з того самого GitHub Pages-сайту і кешує останню успішно прочитану копію. Щоб оновити розклад для всіх користувачів, замініть `schedule.json` у GitHub. Кнопка «Імпортувати JSON» додає розклад лише в браузер поточного пристрою.

## Публікація з iPhone
1. Відкрийте `https://github.com` у Safari та увійдіть.
2. Натисніть `+` → **New repository**.
3. Назва, наприклад `vnau-timetable`, видимість **Public**, створіть репозиторій.
4. В репозиторії натисніть **Add file** → **Create new file**.
5. Створіть `index.html`, вставте вміст відповідного файлу з архіву й натисніть **Commit changes**.
6. Повторіть для `style.css`, `app.js`, `schedule.json`. Назви мають збігатися точно.
7. Перейдіть у **Settings** → **Pages**.
8. У **Build and deployment** виберіть **Deploy from a branch**, гілку `main`, папку `/ (root)`, натисніть **Save**.
9. Зачекайте завершення публікації. Адреса буде приблизно `https://ВАШ-USERNAME.github.io/vnau-timetable/`.
10. Відкрийте адресу в Safari. Для Telegram Mini App створіть/використайте бота через BotFather та вкажіть цю HTTPS-адресу як Web App URL.

## Перевірка джерела ВНАУ
Сторінка `http://81.30.162.30/time-table/group?type=0` не була надійно доступна інструменту перевірки в цьому сеансі. Тому структура HTML/запитів офіційного сайту не припускалася і парсер не вигадувався. Спочатку перевірте сторінку в Safari. Для автоматичного імпорту може знадобитися окремий сервер-проксі, якщо джерело не надає доступ до даних з браузера.
