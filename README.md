# ДеПара? 4.0 — чиста версія

Зібрано з наданого архіву Vnau_rozklad_par-main(3).zip. Резервна копія не створювалася.

## Що працює
- Оригінальний інтерфейс із 5 розділами, адаптований для телефону та Telegram WebApp.
- Реальний розклад із `data/groups/{id}.json`, вибір групи з `data/catalog.json`, перегляд днів, локальний кеш розкладу.
- Завдання, нотатки, оцінки, відвідування, XP — зберігаються локально в браузері (localStorage).
- Перемикання світлої/темної теми.
- Збережені дані `data/`, `schedule.json`, скрипти `scripts/`, `parser.py`, `requirements.txt` та GitHub Actions `.github/workflows/`.

## Що ще НЕ працює без сервера
- Реальні групові чати, друзі, хмарна синхронізація особистих записів, push-сповіщення. У розділі «Спільнота» зараз чесно показано заглушки.
- Для цього потрібні окремий бекенд, база користувачів та перевірка підпису Telegram initData на сервері. Не довіряйте `initDataUnsafe` як підтвердженню особи.

## Як встановити
1. Розпакуйте ZIP.
2. Відкрийте GitHub → репозиторій `Vnau_rozklad_par` → гілка `main`.
3. **Перш ніж видаляти старе, переконайтесь, що потрібні файли даних уже присутні у новому архіві.** У цьому архіві вони є.
4. Замініть вміст репозиторію файлами **зсередини** папки `DePara4`, не завантажуйте саму папку як вкладену.
5. Переконайтесь, що GitHub Pages публікує `main` → `/(root)` (якщо Pages налаштований на публікацію з гілки).
6. Дочекайтесь завершення GitHub Actions і перевірте розклад у браузері.

Під час оновлення GitHub Pages може показувати стару версію через кеш. Відкрийте сайт із `?v=4`.
