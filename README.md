# ДеПара? REBORN

Статичний сайт і Telegram Mini App для розкладу ВНАУ.

## Активна структура
- index.html — вхідна сторінка GitHub Pages.
- reborn-preview/ — активні JS/CSS і тестова сторінка.
- data/groups/ і data/catalog.json — розклад та каталог студентських груп.
- data/teachers/ — розклади викладачів.
- data/campus/ — вільні аудиторії.
- scripts/ і .github/workflows/ — оновлення розкладів та перевірки.

## Що залишено
Розклад, найближча пара, відлік, пари на день, історія змін, викладачі, аудиторії, вибір групи, оформлення та поширення PNG через пристрій.

## Що відключено
Cloudflare Worker/D1, серверна авторизація Telegram, хмарна синхронізація, серверне поширення від імені бота, чати, старі навчальні віджети та XP. GitHub Pages не може самостійно приймати Telegram webhook. Telegram initDataUnsafe не є серверним підтвердженням особи.

## Перевірки
Запустити: node scripts/audit-static.cjs
Далі — GitHub Actions та браузерні тести. До їх проходження не зливати гілку очищення у main.

## Резерв
Експериментальні зошити, старі JS/CSS і версії залишені в репозиторії для можливого повернення, але не завантажуються головною сторінкою. Дані розкладу та скрипти синхронізації не видаляти.
